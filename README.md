# Ping-Pong-Game 🎮  

A classic **Ping Pong Game** developed using **HTML**, **CSS**, and **JavaScript**. This project provides a fun and interactive experience while showcasing fundamental web development and game programming concepts.

---

## 🚀 Features  

- **Double Player Mode**: Play against a challenging opponent.  
- **Responsive Controls**: Move your paddle smoothly to block and return the ball.  
- **Score Tracking**: Keep track of your points and aim to beat the opponent.  
- **Dynamic Gameplay**: The game speed increases as you progress, making it more challenging.  

---

## 🎨 Technology Stack  

- **HTML**: Structure of the game.  
- **CSS**: Styling for the game layout.  
- **JavaScript**: Game logic, AI behavior, and animations.  

---

## 📋 How to Play  

1. Clone the repository:  
   ```bash
   git clone https://github.com/<your-username>/Ping-Pong-Game.git
   ```  

2. Open `index.html` in your favorite browser.  

3. Use the **arrow keys** (or assigned keys) to control your paddle.  

4. Score points by preventing the ball from hitting your side and bouncing it past the AI opponent.
